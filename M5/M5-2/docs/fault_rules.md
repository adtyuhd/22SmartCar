# 故障判定规则

## 1. 传感器降频

- 默认阈值：10Hz。
- 持续时间：2秒。
- 监控范围：fault_rules.critical_topic_patterns。
- 只有收到过消息、且频率持续低于阈值时，才判定降频。
- 新发现但尚未收到消息的话题，按未初始化处理，不立即判定降频。

## 2. 传感器掉线

- 默认超时：3秒。
- 仅监控配置指定的关键话题。
- 超时后产生故障事件。
- 恢复收包后记录恢复事件，并更新故障持续时间。

## 3. 资源告警

- CPU 使用率高于 85%。
- 温度高于 85 摄氏度。
- 电压低于 10.5V。

只有系统确实能够读取对应数据源时才进行判断。
无法读取的指标必须标记为 unavailable，不得伪造数值或填零。

## 4. 故障时效

故障检测周期和事件发布机制需要保证故障发生后1秒内能够显示在面板上。
