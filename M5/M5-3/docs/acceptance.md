## 自动化验收

| 标准 | 证据类型 |
|---|---|
| 急停 202 仅代表请求，运行中/未确认复位拒绝 | 既有 HTTP 测试，FakeSafety/FakeReferee |
| 空 ID、无关 ID、畸形反馈不能解除主机锁存；仅当前成功反馈可解除 | SafetyController 真实逻辑，模拟发布器 |
| 急停严格停用、复位不激活、旧 ENABLE 回调不能覆盖新 STOP、停用失败禁止复位 | EmergencyStopGuard 真实逻辑，模拟控制器服务 Future |
| 参数回读不一致恢复原值，跨节点场景失败补偿 | 真实热切算法，模拟参数调用 |
| 多写入器链完整、篡改拒绝继续追加、可信检查点发现截断 | 实际临时 JSONL 文件与验证工具 |
| 跳过无后端返回 501、页面禁用、严格输入校验、危险状态不调用后端 | 实际 HTTP 路由与模拟后端；无真实任务跳过 |
| 真正 ROS context/执行线程启动和退出，实际参数服务更新及回读，越界拒绝 | 独立 DDS 域中的真实 ROS 2 + 模拟目标节点 + HTTP ASGI 集成 |
| 裁判 START/PAUSE/STOP、状态接口、未配置模型拒绝、审计链验证 | 同一隔离 ROS 集成测试；不代表任务调度器响应 |

所有测试须使用系统 Python 3.10 与已加载的 Humble 环境。测试结果以实际执行输出为准，单元测试不触发真实底盘控制。

## 仍需现场或其他项目配合

1. 机器人负责人将 Guard 接入实际节点；本次不修改其他项目、不增加独立常驻机器人进程。
2. 确认控制器服务返回与实际底盘停止、速度来源仲裁、物理急停链路一致；测量通信中断、服务不响应、故障与急停的停车距离/延迟。
3. 确认匹配反馈解除锁存后，比赛和底盘仍保持停止，必须单独人工恢复；验证与裁判设备的真实通信、倒计时与加罚业务规则。
4. 配置真实参数节点、模型文件与场景；验证模型实际加载完成、失败回退、参数变化对运动与感知的效果。CSV 与参数回读不能代替这些证据。
5. 当前跳过不可用。真实调度器若无安全取消接口，需由其项目负责人提供接口；M5-3 仅交付适配协议、不可用状态、HTTP/页面和模拟测试。
6. 现有集成使用进程内 HTTP ASGI 与真实 DDS，不覆盖外部浏览器交互、真实 TCP 网络部署或实车端到端运行。审计需按部署流程保存可信检查点并限制文件写权限。
